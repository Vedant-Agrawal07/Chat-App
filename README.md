# 💬 Real-Time Chat App

A full-stack real-time chat application built with React, Node.js, MongoDB, and Socket.IO. It includes modern messaging features like private/group chats, typing indicators, real-time notifications, search functionality, and secure user authentication.

---

## ✨ Features

- 🔐 **User Authentication**
  - Register/Login with encrypted passwords
  - Profile picture support

- 👥 **Friend System**
  - Add people using their **email**
  - Search for users or friends

- 💬 **Chat Functionality**
  - One-on-one private chats
  - Group chats with **admin controls** (add/remove members)
  - Typing animation
  - Real-time message delivery using Socket.IO

- 🔔 **Notifications**
  - Instant notification system for new messages

- 🛡️ **Security**
  - Passwords encrypted using **bcrypt**
  - JWT-based authentication

---

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB + Mongoose
- **Real-Time**: Socket.IO
- **Auth**: JWT (JSON Web Tokens)
